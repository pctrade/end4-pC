IMPLEMENTED AREAS
-----------------
1. Tower-defense widget

The game is a native Quickshell/QML background widget. It has:
- Infinite waves.
- Boss waves every fifth wave.
- Increasing wave compositions.
- Grunts, runners, swarms, armored enemies, and bosses.
- Four tower roles: Bolt, Frost, Cannon, and Arc.
- Tower placement validation against the route.
- Target modes: First, Closest, Strongest, and Last.
- Tower levels through level 5.
- Current stats and next-level damage preview.
- Upgrade cost, selling, and targeting controls.
- Pause, 1x/2x/4x speed, restart, and next-wave controls.
- Persistent high score.
- Persistent sound-enabled setting.
- Floating damage numbers and hit effects.
- Directional projectile trails.
- Wave and boss banners.
- Entry and Core landmarks.
- Native vector SVG art for tower and enemy silhouettes.

Tower-defense SVG assets are in:
modules/ii/background/widgets/towerDefense/assets/

Assets currently include:
- battlefield.svg
- tower-bolt.svg
- tower-frost.svg
- tower-cannon.svg
- tower-arc.svg
- enemy-grunt.svg
- enemy-runner.svg
- enemy-swarm.svg
- enemy-armored.svg
- enemy-boss.svg

The current pass adds battlefield.svg as a layered illustrated backdrop beneath the route and actors. It also keeps the route and simulation source of truth in TowerDefenseGame.qml.

2. Native game audio feedback

TowerDefenseGame.qml imports qs.services and uses the existing Audio service. Event sounds are played for:
- Normal wave start.
- Boss wave start.
- Tower upgrades.
- Game Over.

The bottom status strip has an SND/MUTE toggle. The setting is persisted in:
modules/common/Config.qml
under background.widgets.towerDefense.soundEnabled.

This is deliberately event-feedback audio using the shell’s existing audio service. It does not spawn unmanaged processes. If adding longer background music later, integrate through a lifecycle-safe native media component rather than starting a detached process.

3. Lyrics rebuild

Existing lyrics architecture:
- services/LyricsService.qml gets synchronized lyrics using scripts/lyrics/lyrics.py.
- modules/common/widgets/Lyrics.qml renders the lyrics.

The lyrics renderer was rebuilt from a static seven-slot text arrangement into a smooth ListView centered on the active line. The current pass adds:
- 50ms timing synchronization.
- LyricsService.playbackPosition.
- LyricsService.activeWordIndex.
- Enhanced-LRC word timing parsing.
- Native word-by-word highlighting.
- A soft background highlight behind the currently sung word.
- Active word color emphasis.
- Active-line scale and opacity hierarchy.
- Smooth vertical tracking and transitions.
- Graceful line-only fallback where word timing is not available.

The backend now outputs JSON lines followed by §ok. It still supports the old delimiter format in LyricsService.qml for compatibility.

Enhanced LRC support is implemented in:
scripts/lyrics/lyrics.py

The QML lyric renderer is in:
modules/common/widgets/Lyrics.qml

The service is in:
services/LyricsService.qml

KNOWN DESIGN INTENT
-------------------
The visual direction is a restrained indie vector-game treatment integrated with end4-pC’s dark layered surfaces. It intentionally avoids copying Liquify or another game. The important reference principles are:
- Strong hierarchy.
- Rounded but not generic glass everywhere.
- Limited accent palette.
- Distinct silhouettes.
- Readable small-scale roles.
- Smooth motion.
- Active lyric word focus.
- Native lifecycle-safe integration.
